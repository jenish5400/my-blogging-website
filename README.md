# Responsive Blogging Website

A clean, modern, and fully responsive blogging website built from scratch using pure frontend technologies. This project showcases the implementation of structured layouts, semantic styling, and interactive client-side logic.

## 🚀 Live Demo
*(Optional: Once you host your website on GitHub Pages, paste your live link here)*
- **Live Link:** [View Live Website](https://github.io)

## ✨ Features
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewports.
*   **Clean Navigation:** Intuitive navbar for seamless browsing between articles and categories.
*   **Dynamic UI Elements:** Interactive components powered by Vanilla JavaScript.
*   **Modern Typography & Styling:** Clean layouts prioritizing readability and content focus.

## 🛠️ Tech Stack
*   **HTML5:** Semantic structure and accessible content organization.
*   **CSS3:** Custom layouts, flexbox/grid configurations, and responsive media queries.
*   **JavaScript (ES6+):** Client-side interactivity and functional logic.

## 📂 Project Structure
```text
├── index.html          # Main homepage listing the blog posts
├── css/
│   └── style.css       # Layout styles and media queries
└── js/
    └── main.js         # Interactive features and logic
```

## 💻 How to Run Locally
1. Clone or download this repository.
2. Navigate to the project root directory.
3. Open the `index.html` file in any modern web browser.
